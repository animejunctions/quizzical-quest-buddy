# QuizLab - Secure Online Testing Platform

A professional online testing platform with anti-cheat protection, real-time leaderboards, and detailed analytics.

## Features

- **Anti-Cheat Protection**: Tab switching detection with automatic test submission after 3 violations
- **Timed Assessments**: Configurable time limits with countdown timer
- **Real-time Leaderboards**: Track rankings sorted by score
- **Detailed Results**: Question-by-question review with explanations
- **Light/Dark Mode**: Toggle between themes for comfortable viewing
- **Persistent Results**: View your results anytime after submission
- **Admin Dashboard**: Comprehensive test management and analytics

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Supabase (Database)
- shadcn/ui Components
